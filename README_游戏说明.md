# 灵境伙伴 V4 · 开发预览、属性生态与互动机器人

## 新版怎么玩

打开游戏后选择“伙伴图鉴”，即可领养、切换、培养和进化伙伴。默认有烛尾龙、雷耳兔、面包柯、薄荷喵四只伙伴与 2000 星币；36 个原创家族各有三个阶段，共 108 个形态。其余初始形态每只 85 星币；正常养成模式的成长形态通过进化获得，同一家族只领养一次。

默认开启“开发者模式”：每张图鉴卡片均可直接预览，包含未领养、未解锁的最终形态，并可进行临时练习。预览自动切到正面三分之四近景，可旋转查看外形；不消费材料、不解锁、不领取奖励、不写入真实存档。点击“返回真实伙伴”或关闭开发模式恢复正式伙伴。图鉴插画是阶段示意图，实时预览才是实际 3D 外形。

- 18 属性：无属性、火、电、木、土、水、风、冰、金属、光、暗影、音、心灵、毒、岩石、灵魂、格斗、星辰。界面“属性关系”展示实际伤害倍率。每个有属性类型恰有 3 项优势与 3 项弱势，优势 1.5、弱势 2/3 互为反向，同属性 0.8，无免疫；这是结构平衡，不保证所有对局胜率相同。
- 12 个性格子类型映射到四种战斗性格，在实力、健康与疲劳判断之上分别改变进攻、闪避与试探倾向。测试时手动选择其他战斗性格可覆盖物种默认性格。
- 52 个技能配置，伙伴有共享技能、属性技能与家族签名技能；近战必须进入有效范围，远程按弹速与目标轨迹估算命中机会。火球、冰棱、电针、木叶、音波、星辰等采用不同形状与短尾迹，持续喷射绑定实时发射部位。
- 点击场景顶部或对战面板的“停止对战”（也可按 Esc）立即取消练习，清理攻击和受击状态，不记录胜负或奖励，可以立刻更换精灵。
- 中央主人变成原创小电视机器人，接管后使用 W/A/S/D、方向键或按住方向按钮移动，松手即停；有实体碰撞、跟随镜头、呼唤与自行归位。接待区随朝向变化，靠边或建筑旁会选取安全的正面位置；完全被挡时提示移动到空旷处。呼唤时限按路程与落地高度调整，避免高空伙伴尚未抵达就失效。机器人视频第一视角可近距离看伙伴。
- 八种无摄像头互动：招手、打滚、蹭蹭、歪头、眨眼、微笑、觅食、休息。地面互动先落地，打滚期间禁止主动移动。开启摄像头后识别七种标准手势及微笑、眨眼、惊讶；处理在本机，不保存视频。蝙蝠／企鹅的纹理眼睛暂不支持独立闭眼。

- 喂食：8 星币 + 1 食物，24 经验、9 亲密度；陪玩：12 星币，28 经验、12 亲密度。
- 力量、耐力、敏捷：每次 18 星币，42 经验、3 亲密度，并提升对应训练项；上限 20 点。训练增加负荷，免费休息和喂食降低负荷。
- 初次进化：Lv.3、亲密度 35、80 星币、1 进化晶石。最终进化：Lv.7、亲密度 60、160 星币、2 晶石。界面逐项说明缺少条件；进化保留个体 ID、经验、训练、体质、记忆和技能。
- 胜利奖励 110 星币、2 食物、90 经验和 1 晶石；练习败北仍获得 45 星币、1 食物、45 经验。日常成功觅食也获得少量经验和资源。
- 培养真实影响战斗生命、伤害、防御、速度；速度增长有上限，不会因训练或恢复体力无限加速。战斗中不可临时换伙伴或进化。
- 选择“属性对战”可指定任意图鉴形态作为模拟对手。无需对战也能在左侧实时世界查看已领养伙伴；数字键 1–6 切换镜头。
- 练习赛限时 90 秒，击败或成功撤退可提前结束；到时按剩余生命比例判定，接近平手则记为平局。奖励只结算一次。火系新增焰尾火球、无属性新增星屑弹；正常进攻按伤害技能的真实三维射程控制高度，躲闪与脱离仍可利用高空。

每只伙伴分别保存生理、后天记忆、技能熟练度/冷却与培养数据，存档位于当前浏览器的 `digitalFlySpiritCollectionV1`。初次使用新版迁移旧实验场当前个体的生理和记忆；不清空旧存档。不同端口或浏览器使用不同本地存档；清除网站数据会丢失进度。

画面使用 Quaternius 的 CC0 动画模型和原有短腿/四足身体适配器：22 个家族使用导入骨骼模型，其余家族保留适合的软体步态。幼体强调大头圆润；成长形态改变头身比例并增加肩部／尾部轮廓；终极形态扩展冠、背部、翼部轮廓。体型、阶段配色和贴体花纹分别配置；108 个形态并非 108 个完全独立模型或动画骨架。模型按需加载、独立克隆骨架，替换后释放本地资源；摄像头识别库只在开启摄像头时加载，隐藏页面暂停仿真和渲染。详细来源见 `app/public/models/creature-monsters/ATTRIBUTION.md`。

软件 WebGL（SwiftShader / llvmpipe 等）自动关闭阴影、降低像素分辨率并减少装饰实例；Intel 核显维持原有优化档。物理固定 30 Hz，渲染掉帧时采用有上限的补帧，避免战斗时间被 GPU 帧率大幅拖慢。

**科学边界：**不是纯规则程序，也不是完整果蝇大脑自主学会了战斗。MaleCNS 真实连接组的感觉—运动子回路仍参与气味、甜苦味、逼近刺激、逃逸与进食反应；连接权重固定，神经活动随输入和先前状态动态变化，未实现生物突触可塑性训练。等级、进化、属性、表情、战术和骨骼动画属于新增游戏层；持久后天经验由游戏学习层保存，不等同真实神经记忆。每个个体独立神经活动、冷却、生理与记忆，共享只读线路数据而不共享活动数组。

验证命令（在 app 目录）：`npm test`、`npm run build`、`node tests/v4-smoke.mjs`。UI 回归在独立短时无头浏览器运行并关闭，不会打开 Codex 侧栏或读取用户浏览器存档；摄像头真实设备权限需用户点击后验证。

## 启动方式

- 推荐：双击项目根目录的 `启动游戏.cmd`，不依赖 VS Code PowerShell 调试扩展。
- VS Code：按 `Ctrl+Shift+B`，运行默认任务“启动数字果蝇游戏”。
- PowerShell 终端：运行 `./启动游戏.ps1`。不要使用编辑器右上角的 PowerShell“调试文件”按钮；该按钮依赖 PowerShell Editor Services，与游戏运行无关。

这是一个用来验证“果蝇连接组是否真的改变游戏行为”的可运行原型，已加入收集养成，但不是完整的商业 RPG。

## 已实现

- 自主活动的简单可爱三维生物和可旋转、缩放的 3D 实验场。
- 甜果、苦果、食物气味和会逼近的威胁。
- 由 MaleCNS v1.0 真实连接数据抽取的视觉、嗅觉、甜味、苦味、逃逸和进食子网络。
- `LC4/LPLC2 -> DNp01` 逼近逃逸通路。
- 甜味 GRN 到 `MN9` 进食通路。
- 苦味 `LB1a-d -> GNG087` 对进食输出的抑制效果。
- 实时神经活动可视化和可解释事件日志。
- 真实连接/打乱连接对照实验。
- DNp01 与 MN9 沉默实验。
- 鼠标拖动旋转观察、滚轮缩放；单击地面可放置甜果。
- 主人呼唤、亲手喂食、温柔抚摸和惊吓会改变亲密度与恐惧记忆。
- 可训练的冲刺攻击；命中后通过奖励增强攻击熟练度和自信。
- 学习型攻击与真实 DNp01 逃逸输出竞争，危险太强时仍会优先逃跑。
- 战术判断会比较敌人实力与敌意、攻击收益、个体性格、生命、体力、退路和主人指令；可选择攻击、撤退、观察或无视。
- 主人指令只是决策加权：明显没有胜算时可以拒绝攻击，没有退路时也不会假装能够逃跑。
- 后天记忆保存在浏览器本地，可用“清除后天记忆”恢复初始状态。
- 四种可切换场景：生态花园、狭窄遗迹、夜间觅食和巢穴防御；场景会同步改变地形、障碍、照明、食物、敌人参数、收益与退路。
- 三维飞行身体：起飞、爬升、巡航、俯冲、体力消耗和降落；飞行高度足够时可以越过低矮障碍。
- 玩家外形替换为原创“四足萤翼兽”：圆润薄荷身体、四条短腿、大眼睛、触角、叶片翅膀与发光尾尖；地面采用交替四足步态，飞行自动收腿振翅。
- 地图扩展到 3200 × 2000 单位；地面探索约 92 单位/秒，空中巡航约 620 单位/秒，飞行仍明显更快但便于观察和操控。
- 双果蝇三维空战：双方会盘旋、侧飞、抬升、俯冲、移动施法与改变航线闪避；身体朝向和实际飞行方向相互独立。
- 真实弹道与差异化受击：远程技能沿发射时的预测直线飞行而非自动追踪；撞击、水弹、电击、火焰、毒素、震荡和旋风拥有不同的后仰、翻滚、痉挛、颤动、掀飞与旋转反应。
- 撤退与追击：低生命且明显处于劣势时会转身逃跑；追击方会综合追击策略、性格、剩余生命、体力和双方速度，决定追、停手或继续正面交战。
- 闭环战斗身体控制：不再播放预设的蛇形、转圈或奇袭路线；每帧把相对距离、目标速度、预计碰撞、弹道方向、高度差与体力合成为连续转向、加速、制动和升降输出，距离过近时由身体反射主动分离。
- 连接组视觉与可塑闪避：对手和来袭弹道会刺激 LC4/LPLC2 逼近视觉通路，真实神经逃逸活动参与闪避强度；闪避成功或失败会调整并持久保存横移/升降偏好。
- 有限视觉与气味标记：离开视觉距离后只保留最后目击位置并停止精确射击；所有属性都能使用低消耗“气味标记”，命中后由嗅觉在限定时间内跨越整张地图定位目标。
- 空中碰撞：普通接触只结算一次双方轻伤并弹开；冲刺撞击接触时只对被撞者执行重击、击退和失衡，避免重叠后逐帧抖动。
- 展示级立体生态战场：地图扩展到 7200 × 4800，飞行上限约 1600；包含山脉、峡谷河道、森林带、遗迹高台和高空导航环，并使用按双方距离自动缩放的双目标跟随镜头。
- 大型地形具有真实体积与高度碰撞；低空无法穿山或穿过高台，爬升到地形高度以上后才能越过。
- 战场辨识：我方/对手采用不同颜色的脚下标记、头顶名称与浮动生命条，并在界面显示当前战术。
- 自主身体控制器会不断选择局部巡游目标并产生弧线转向；气味、主人、敌人与逃逸决策可覆盖巡游方向。
- 统一三维碰撞体覆盖果蝇、敌人、主人、洞穴、岩石、池塘、植物、墙和地图边界；高速运动采用分步检测防止穿墙，飞行高度足够时才会越障。
- 完整生物状态：体型、力量、耐力、代谢、视觉、嗅觉、步行/飞行速度、贪食、耐心、社交性，以及生命、体力、饥饿、疲劳、疼痛、压力、兴奋、中毒、翅伤和腿伤。
- 六类可用技能：冲刺撞击、毒液弹、火焰喷射、连锁雷弧、孢子爆发和岩壳防御；统一支持距离、范围、体力消耗、冷却、等级和状态效果。
- 属性注册表与克制接口已包含无属性、火、电、木、土、水和风；角色、敌人和技能属性彼此独立，可继续扩展。
- 生物状态、个体体质、属性和技能等级会保存在浏览器本地。
- 世界尺寸扩展到 1500×950；镜头支持旋转、缩放和右键平移。
- 6 个多属性敌人具有独立的强度、敌意、生命、防御和巡逻状态；两座洞穴负责出发、返巢、休息与回血。
- 敌人会随机巡逻一段时间后自行返巢；战败后保留在地图中并撤退，不再突然消失或随机传送。
- 技能特效遵守释放方式：护盾和范围效果跟随主体，火焰等持续喷射的起点跟随施法者；水弹、毒液、电针、风刃和气味弹离开发射者后按独立弹道飞行。

## 验证

```powershell
cd app

```

V4 的 139 项单元测试覆盖独立神经状态、培养进化、存档迁移、移动限速、射程、蒙皮地面边界、18 属性矩阵、开发预览、机器人碰撞、安全接待点和特效预算。`npm run smoke` 在独立浏览器上下文检查 108 张图鉴卡、预览存档隔离、两处停止对战按钮、手动互动、机器人移动及三种页面宽度。`node tests/v4-visual-smoke.mjs` 检查实际三段模型、新属性对战和机器人画面。`npm run smoke:progression` 保留较长的培养回归：原始 18 家族领养样本、两次进化、刷新恢复与胜负奖励一次结算。运行前需在 `127.0.0.1:4173` 启动生产预览，或通过 `SPIRIT_TEST_URL` 指定测试服务。测试不会清空用户浏览器存档；测试上下文运行后关闭。

模型骨骼审计：运行开发服务后，以 `SPIRIT_ART_TEST_URL` 指定该服务地址，再执行 `node tests/creature-art-smoke.mjs`，检查导入模型的头部、行走/受击/倒地与地面边界。这属于数值和界面回归验证，不能替代完整动作质量审核；模型没有对应动画时仍会使用备用动作，摄像头真实识别需要用户授权后现场测试。


## 数据规模

网页子网络包含：

- 95 个神经元种群节点；
- 代表 802 个 MaleCNS 神经元；
- 609 条种群级连接；
- 聚合自 209,941 个真实数据中的突触接触。

完整本地基准使用同一下载包中的 176,422 神经元、6,287,749 条阈值后连接。

## 科学与工程边界

- 网页中是为交互速度设计的“种群级活动模型”，不是逐神经元全脑仿真。
- 传感器到神经元、神经输出到身体动作必然包含工程适配。
- 行走探索使用低层身体控制器；逃逸和进食则由 DNp01/MN9 神经输出门控。
- 子网络中没有伪造生物连接；节点和边都由 FLYB 数据聚合生成。
- 亲密度、恐惧和冲刺攻击是明确标注的游戏扩展层，不属于 MaleCNS 原始连接；它只读取神经输出，不改写原始突触图。
